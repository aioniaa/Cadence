# Cadence 2.5.2

## Highlights

- **Update prompt**: the available-update dialog uses the Mochi dialog pattern with “立即更新” and “暂不更新”.
- **Download dialog**: choosing update opens a separate Mochi download dialog with a progress bar and a “取消下载” button. The download can be cancelled at any time.
- **Minimum check duration**: the version-row loading indicator stays visible for at least 3 seconds.
- **Clear results**: manual checks distinguish “当前已经是最新版”, “网络不可用”, and other update-service failures.
- **Version row**: single-line, vertically centered with the loading indicator or chevron.
- Download completes and automatically opens the system package installer. Android's one-time unknown-source confirmation still applies.
